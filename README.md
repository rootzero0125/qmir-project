# 📚 큐미르 읽기전략 & 코넬 노트 자동화 시스템 (Master Specification)

## 1. 프로젝트 개요
사용자가 입력한 지문 이미지와 텍스트를 분석하여, '큐미르 읽기전략' 기호를 자동 생성하고 이를 '코넬 노트' 및 '위계 마인드맵'으로 시각화하여 출력하는 프로그램입니다.

## 2. 개발 스택 (Tech Stack)
- **Frontend**: React (Web APP)
- **Backend**: JAVA (Spring Boot)
- **Database**: PostgreSQL (Supabase)
- **Deployment**: GitHub Actions, Cloudflare

---

## 3. 교재 제작 표준 프로토콜 (Standard Protocol)

### 3.1 정보 위계 및 기호 규칙
모든 정보는 중요도에 따라 아래의 **3단계 위계**를 엄격히 준수합니다.

| 위계 | 기호 | 정의 및 조건 | 연결 번호 및 표시 |
| :--- | :---: | :--- | :--- |
| **1순위** | **네모 (□)** | 글 전체의 대주제 (단 1개). 노트 최상위 제목. | (1), (2), (3) |
| **2순위** | **원 (○)** | 문단별 핵심어 (최대 4개). 코넬 노트 좌측 배치. | ①, ②, ③ |
| **3순위** | **세모 (△)** | 2순위의 하위 항목/부품 (최대 4개). | **빨간 밑줄**, ㉠, ㉡, ㉢ |

### 3.2 논리 관계 기호 (Logic Symbols)
* **인과 관계 (→)**: 원인과 결과를 나타내는 지시어(때문에, 따라서 등) 아래에 삽입.
* **대조 관계 (↔)**: 대조 및 역접 지시어(그러나, 하지만 등) 아래에 **파란색 양방향 화살표** 삽입.

### 3.3 장르별 변형 가이드
#### [비문학]
- 논리적 선후 관계 및 위계(1, 2, 3순위) 분석에 집중.

#### [문학]
- **네모**: 시공간적 배경 (노트 상단/배경 항목 배치)
- **원**: 중심 등장인물 (인물 관계도 기초)
- **원 숫자**: 사건의 흐름 (시간 순서에 따른 위계)
- **양방향 화살표**: 인물 간 갈등 또는 핵심 논리 반전 시점
- **밑줄**: 심리 묘사, 태도, 사건의 복선

## 4. 출력 이미지 프로세스 (난이도 4 기준)
프로그램은 다음 세 가지 요소를 유기적으로 결합하여 최종 이미지를 생성합니다.

1. **본문 분석 단계**: 지문 이미지 위에 기호(네모, 원, 세모)와 번호가 표시된 이미지.
2. **배경지식 통합**: 별도 이미지(장단점 표 등)의 데이터를 추출하여 본문 키워드와 매칭.
3. **최종 출력물**: 본문 분석과 배경지식을 바탕으로 생성된 **'코넬 노트'**와 **'위계 마인드맵'** 통합 레이아웃.

---

## 5. 시스템 운영 원칙
- 모든 코드는 **Antigravity Agent**가 이 지침서를 숙지하여 작성한다.
- 환경 변수(`.env`)는 보안을 위해 GitHub에 업로드하지 않는다.
- 비전공자 사용자가 직관적으로 조작할 수 있는 UI/UX를 제공한다.
