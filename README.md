# 큐미르 읽기전략 & 코넬 노트 (Qmir Reading Strategy & Cornell Note)

이 저장소는 **큐미르 읽기전략**과 **코넬 노트(Cornell Note)** 방식을 결합한 지침서를 바탕으로 자료를 정리하고 기록하는 공간입니다.

## 1. 큐미르(Qmir) 읽기전략이란?
큐미르 전략은 효과적인 독서와 지식 흡수를 위한 체계적인 접근법입니다. 
- **Q (Question, 질문하기)**: 읽기 전에 핵심 질문을 던집니다.
- **M (Main idea, 핵심 파악)**: 글의 주요 논지와 주제를 파악합니다.
- **I (Insight, 통찰 및 영감)**: 읽으면서 얻은 새로운 깨달음이나 영감을 기록합니다.
- **R (Review, 복습 및 요약)**: 전체 내용을 되돌아보고 핵심을 요약합니다.

## 2. 코넬 노트(Cornell Note) 작성법 
노트를 세 가지 영역으로 나누어 효율적으로 정보를 조직화합니다.
- **단서 영역 (Cue Column)**: 핵심 키워드, 질문, 아이디어를 적습니다.
- **노트 영역 (Note-taking Area)**: 읽거나 학습한 본문 내용을 요약하고 기록합니다. 
- **요약 영역 (Summary Area)**: 페이지 하단에 전체 내용을 1~2문장으로 압축하여 요약합니다.

## 3. 활용 가이드
이 저장소에 추가되는 모든 노트(Markdown 파일)는 위 두 가지 지침을 결합한 템플릿 구조를 따릅니다.

### 📝 기본 템플릿 
```markdown
# [책/자료 제목]
- **날짜:** YYYY-MM-DD
- **주제:** 

## 📌 Qmir 전략
- **Q (질문):** 
- **M (핵심):** 
- **I (통찰):** 
- **R (리뷰):** 

## 📓 코넬 노트
| 단서(Cue) | 노트본문(Notes) |
|---|---|
| 키워드/질문 | 상세 내용 요약 및 정리 |

### 💡 요약(Summary)
- 전체 내용 1~2줄 요약
```
